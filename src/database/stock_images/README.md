# Stock Images

Organize reusable stock images here for seeded Cartly data.

- `category/` contains folders for seeded product categories.
- `ingredient/` contains folders for seeded standard ingredients.
- `recipe/` contains folders for seeded sample recipes.

Place image files inside the matching folder, for example:

```text
src/database/stock_images/ingredient/rice/rice.png
src/database/stock_images/recipe/chicken_fried_rice/chicken-fried-rice.png
```
